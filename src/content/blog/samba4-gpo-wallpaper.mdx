## Provisionar o domínio

```bash
samba-tool domain provision \
  --use-rfc2307 \
  --realm=LAB.ARTHLABS.DEV \
  --domain=LAB \
  --server-role=dc
```

## GPO de wallpaper

A GPO aponta para `\\dc\netlogon\wallpaper.bmp`. O caminho **precisa** ser UNC — caminho local não funciona.
