## O problema do PATH em shells não-interativos

`nvm` vive num shell interativo. Quando o GitHub Actions abre SSH e roda comandos direto, o PATH não tem `node`. A solução é carregar o nvm explicitamente:

```bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
```

## Rollback

Antes de subir a nova versão, a pipeline tagueia a imagem anterior como `previous`. Se o healthcheck falha, `docker compose` sobe a `previous` de volta.
